07 / THE LOGIC

A simple idea, with explicit rules

How risk appetite changes the market filter

LowBelow the Nifty 200-day average, move the model to cash and pause new purchases.

ModerateBelow that average, keep the five strongest existing positions and hold the rest in cash.

AggressiveIgnore the Nifty market filter and stay invested in the selected stocks.

01

Find liquid stocks

Start with NSE index constituents and rank candidates by their average daily traded value over roughly three months.

02

Rank momentum

Blend six- and twelve-month price returns, ignoring the latest 21 trading days. Select the strongest eligible names.

03

Control exposure

Use inverse volatility weights. Choose low (cash below the Nifty 200-day), moderate (retain five existing holdings and cash), or aggressive (keep buying without the Nifty trend filter). The optional stock 200-day screen remains independent.

04

Review the model basket

Apply the rules to the latest available closing prices. Show each eligible stock’s target weight and the price date; recalculate when settings change.

READ THE RESULTS CAREFULLY

Backtests are research, not a return promise.

The saved configuration was selected using historical data. Current index membership, execution assumptions and changing market conditions can make simulated results too optimistic. The three-year windows reuse that selected configuration and are not independent prospective results. Market prices and constituents are provided by external data sources.
